隐私与个人信息保护

《零食史莱姆》隐私政策

更新日期：【填写实际日期】

生效日期：【填写实际日期】

《零食史莱姆》（以下简称“本游戏”）由 lutyjlu的工作室（以下简称“我们”）开发和运营。我们重视您的个人信息与隐私保护。本政策说明您使用本游戏、阅读本政策网页以及与我们联系时，相关信息的处理方式。

本游戏为可离线运行的单机游戏，无需注册或登录账号。正常游玩过程中，本游戏不主动收集或上传您的个人信息，不提供广告投放、用户行为统计或个人画像功能。

01我们如何处理您的信息

正常游玩

您无需提供姓名、手机号码、身份证号码、电子邮箱等个人信息，即可使用本游戏。

本游戏不主动读取或收集您的通讯录、短信、通话记录、照片、精确位置信息，以及 IMEI、IMSI、OAID、广告标识符等设备标识信息，也不跟踪您在其他应用中的活动。

本地运行数据

游戏运行过程中，角色状态、关卡状态、音量和操作设置等数据在您的设备本地处理，不会由本游戏上传至我们的服务器。

游戏引擎或操作系统可能在设备本地生成用于运行及故障排查的缓存、临时文件或运行日志。本游戏不自动向我们上传这些文件。

本游戏不提供云存档或跨设备同步服务。

您主动联系我们

如果您通过邮箱 805851728@qq.com 联系我们、反馈问题或提出隐私相关请求，我们会收到您的发件邮箱地址，以及您主动提供的文字、截图或其他附件。

我们仅在答复咨询、排查问题、处理请求所必需的范围内使用这些信息，不会将其用于广告营销或个人画像。

您可以自行决定是否提供上述信息。不提供反馈信息不影响正常游玩，但可能影响我们了解和解决您反馈的问题。请勿发送与问题无关的身份证件、密码、金融账户等敏感信息。

02设备权限

本游戏的核心玩法不需要使用摄像头、麦克风、定位、通讯录、短信、通话记录或读取个人媒体文件等权限，也不会为核心玩法向您申请上述权限。

游戏运行所需的资源读取、画面显示、声音播放和操作输入，在操作系统允许的正常应用运行范围内完成。

03第三方组件与平台服务

本游戏使用 Unity 游戏引擎及用于画面、输入、动画和物理效果等功能的技术组件。当前版本未启用面向玩家的第三方广告、行为分析、账号登录或自动崩溃上报服务。

您通过 TapTap 等平台下载、更新、评价本游戏，或使用平台账号与社区功能时，相关平台会按照其自身的隐私政策处理信息。本游戏不会因您从该平台下载游戏而自动获取您的平台账号信息。

本政策网页的托管

本政策网页通过 GitHub Pages 提供，不设置反馈表单、广告、访问统计脚本或用户追踪功能。GitHub Pages 会为安全目的记录和保存访问者的 IP 地址；相关信息处理请参阅 GitHub 隐私声明。网页访问与离线游玩是不同场景，阅读本网页不会使本游戏开始上传您的游戏运行数据。

04信息的保存与保护

正常游玩产生的运行数据由您的设备本地处理，我们不建立用于保存玩家个人信息的游戏服务器。

对于您主动通过邮箱提供的信息，我们仅在完成相关咨询、问题处理或请求所必需的最短期限内保存；处理目的实现后，将删除或匿名化处理，法律法规另有保存要求的除外。

我们会采取与信息处理情况相适应的保护措施，将反馈信息的访问范围限制在处理相关事项所必需的人员之内。

05信息的共享、转让与公开披露

我们不会出售您的个人信息，也不会将您主动提供的反馈信息用于第三方广告或营销。

除依法取得您的相应同意，或法律法规规定的其他合法情形外，我们不会向其他组织或个人提供、转让或公开披露您的个人信息。

本游戏不通过联网功能向境外传输您的游戏运行数据或个人信息。

06您的权利

您可以自主决定是否向我们发送反馈，以及提供哪些信息。

对于您主动提供给我们的个人信息，您可以通过邮箱 805851728@qq.com 请求查阅、复制、更正、补充、删除，或者依法撤回同意、限制或拒绝相关处理。我们会在进行必要核实后依法及时处理，不会要求您提供与请求无关的信息。

本游戏无需注册账号，因此不存在游戏账号注销事项。对于设备本地的应用数据，您可以通过操作系统提供的应用管理功能进行管理或清除，具体以您的设备支持的方式为准。

07未成年人保护

本游戏不会因玩家为未成年人而额外收集其个人信息。

未成年人应在监护人的指导下阅读本政策，并合理安排游戏时间。不满十四周岁的未成年人如需向我们发送包含个人信息的反馈，应由监护人代为联系或在取得监护人同意后提供。

如果监护人发现未成年人向我们提供了不必要的个人信息，可以通过邮箱 805851728@qq.com 联系我们，我们会核实并依法处理。

08本政策的更新

如果游戏功能或信息处理方式发生变化，我们会相应更新本政策，并通过游戏内提示或其他适当方式告知您。

如果未来新增需要处理个人信息的功能，我们会在相关处理发生前说明处理目的、方式、信息种类及您的权利，并依法取得所需授权，不会仅以您继续使用游戏作为新增信息处理活动的授权。
